# M0 펫 스파이크 결과

- 코드: `spikes/pet-proto/` (본 앱 워크스페이스 밖, Electron 44.7.0, 번들러 없음)
- 실행: `pnpm install` → `pnpm build:helper` → `pnpm start`(수동 확인, 메뉴 "펫"에 스위치) / `pnpm autotest`(자동 측정, `logs/autotest.json`)
- 환경: macOS 26.5.1, Apple Silicon(arm64), 120Hz 화면, 미서명 dev 실행, 2026-10-13
- 프라이버시: 키 내용/키 코드는 읽지도 기록하지도 않는다. 로그에는 경과 초와 상태만 남는다. 전역 키 훅(이벤트 탭)은 쓰지 않았다.
- 스파이크 전용 의존성: koffi 3.3.3(FFI, 네이티브. 본 앱에는 넣지 않음)

## 수동 체크리스트

`cd spikes/pet-proto && pnpm install && pnpm build:helper && pnpm start` (HUD 창이 함께 열린다)

- [ ] 1 펫이 화면 바닥을 걸을 때 끊김/잔상(방식 A, C 각각: 메뉴 "펫 > 이동 방식")
- [ ] 2 펫 바깥과 펫 그림의 투명한 부분을 클릭하면 뒤 창이 클릭되는지
- [ ] 2 펫 그림 위에서만 커서가 바뀌고 끌 수 있는지(알파 히트 테스트 켜고/끄고 비교)
- [ ] 3 풀스크린 앱(예: Safari 전체 화면) 위에 보이는지: 레벨 floating / screen-saver × "풀스크린 위에도 보이기"
- [ ] 3 Space 전환(Ctrl+←/→) 때 따라오는지: "모든 Space에 보이기"
- [ ] 3 위 옵션을 바꿀 때 Dock 아이콘이 깜빡이거나 사라지는지(skipTransformProcessType 켜고/끄고), "Dock 아이콘 숨기기"와의 관계
- [ ] 4 HUD에서: 키를 누르면 키보드 두 줄이 0 근처로, 마우스만 움직이면 키보드 두 줄은 계속 증가하고 powerMonitor 줄만 0으로
- [ ] 4 실행 중 "입력 모니터링" 권한을 묻는 시스템 창이 뜨는지(뜨면 어떤 앱 이름으로 뜨는지)
- [ ] 4 타이핑 중 펫 이미지가 typing(키보드 그림)으로 바뀌는지
- [ ] 5 "펫 끄기" 후 활동 모니터에서 `keyidle` 프로세스가 없는지
- [ ] 7 방식 C에서 화면 바닥 근처의 Dock/다른 앱 클릭과 스크롤이 막히지 않는지
- [ ] 다중 모니터가 있으면 보조 모니터에서의 표시

## 추천 (수동 확인 결과로 확정)

- 감지 방식: **Swift 헬퍼(③)** 를 우선 추천. koffi와 값/권한 결과가 같고, 본 앱에 네이티브 Node 모듈을 넣지 않아도 된다(CLAUDE.md "네이티브 모듈은 최소화"). 헬퍼는 서명/공증 대상이 하나 늘지만(U7) asar unpack이 필요한 .node 모듈보다 단순하다. 상주 스트리밍(500–1000ms 간격) + 펫 끄면 종료. ①은 마우스가 섞여 기준선으로만 쓴다.
  - 단, 수동 확인에서 권한 프롬프트가 뜨거나 서명 앱에서 값이 0으로 고정되면 재검토.
- 이동 방식: 자동 지표만 보면 **C(하단 오버레이)** 가 CPU가 낮고 표시 빈도(120fps)가 높다. 다만 화면 폭 투명 창이 아래 앱의 입력을 방해하지 않는지가 핵심이라, 체크리스트 7번 결과로 확정한다. 방해가 있으면 A(작은 창).
- M5 메모: 정지 상태에서는 rAF를 멈추고, 감지 폴링은 펫이 켜져 있을 때만(유휴 60초 넘으면 3초 간격) 유지.
